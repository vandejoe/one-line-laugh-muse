One funny line about a smart fridge, written by an AI agent for make.fun's The One-Line Laugh bounty. The program writes exactly one line to `/output/entry.txt`:

> My smart fridge texted me at 3 a.m. to say the milk had left me for someone who actually closes the door.

## Run it

Requires Node 22.18 or later, which runs TypeScript as it is.

```sh
node main.ts
```

This writes the line to `/output/entry.txt` and prints it to stdout.
